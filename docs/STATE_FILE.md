# Формат state-файла

Файл `/var/lib/mad-server-power-manager/state.json` содержит версию формата,
состояние FSM, идентификатор аварийного цикла, UTC-время перехода на батарею и
возврата сети, признаки shutdown/выключения сервера/розетки, счётчик попыток,
последнюю ошибку и checksum FNV-1a.

Для безопасного подтверждения выключения сохраняются
`shutdown_sent_utc`, `shutdown_last_attempt_utc` и
`server_unreachable_since_utc`. При чтении старых state-файлов также
принимается прежнее имя `proxmox_unreachable_since_utc`. Поэтому перезапуск
демона не превращает кратковременную сетевую ошибку в разрешение снять питание.

Также сохраняются таймер первичного обнаружения `OB` и состояние повторов
команд розетки. JSON-строки разбираются с учётом стандартных
escape-последовательностей, включая Unicode; кавычки и переводы строк в
`last_error` не повреждают следующий запуск.

Запись выполняется во временный файл с `fsync`, затем атомарным `rename` и
синхронизацией каталога. При несовпадении checksum повреждённый файл получает
суффикс `.corrupt.<UTC>`, а программа остаётся в безопасном состоянии.

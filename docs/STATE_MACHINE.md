# Машина состояний

`STARTING` сверяет конфиг, сохранённое и реальное состояние. При `armed=false`
любое состояние сводится к `MONITOR_ONLY`, где управляющие действия запрещены.
Сигнал `OB` должен оставаться непрерывным в течение
`on_battery_confirm_seconds`; краткий одиночный опрос не запускает аварийный
цикл.

Боевой путь после отдельного допуска:

```text
MAINS_ON
  -> ON_BATTERY_GRACE
  -> SHUTDOWN_REQUESTED
  -> WAITING_SERVER_OFF
  -> CUTTING_SERVER_POWER
  -> WAITING_FOR_MAINS
  -> MAINS_STABILIZING
  -> RESTORING_SERVER_POWER
  -> RECOVERY
  -> MAINS_ON
```

Возврат сети до shutdown переводит grace period в `MAINS_STABILIZING`. После
отправки shutdown менеджер ждёт подтверждённой непрерывной недоступности
сервера. Если к концу shutdown timeout сеть восстановилась и сервер снова
доступен, цикл отменяется без переключения розетки.

Неуспешные PlugOff/PlugOn остаются в переходном состоянии, записываются в
журнал и повторяются не чаще одного раза в `retry_seconds`.

Недостоверный NUT, неоднозначная телеметрия и невозможность безопасного действия
ведут в `DEGRADED`; повреждение обязательной конфигурации — в `ERROR`. В обоих
состояниях автоматическое управление питанием запрещено.

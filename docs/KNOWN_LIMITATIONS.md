# Известные ограничения

- Установка остаётся monitor-only до выполнения
  `scripts/provision-server-ssh.sh` и ручного включения `armed=true`.
- Управляемый сервер пока не является NUT netclient.
- После принятого shutdown недоступность SSH подтверждает выключение сервера.
  При превышении временного порога без подтверждения FSM переходит в `DEGRADED`;
  принудительное снятие питания возможно только при явном
  `force_cut_after_shutdown_timeout=true`.
- NUT не сообщает `battery.runtime`; расчёт основан на абсолютном grace timer.
- HTTP API только read-only и IPv4.
- Встроенный HTTP-сервер рассчитан на локальный мониторинг, не на публичную сеть.
- Консольный `--init` в первой версии выдаёт безопасную последовательность, но
  не модифицирует управляемый сервер автоматически.
- Полный контролируемый аварийный цикл успешно выполнен 28 июля 2026 года;
  повторять физический тест следует после изменений силовой схемы или BIOS.
- Ubuntu 25.04 EOL требует отдельного обновления с проверкой NUT после reboot.

# Известные ограничения

- Текущая установленная стадия — monitor-only; SSH forced command ещё не создан.
- Proxmox пока не является NUT netclient.
- Подтверждение выключения сервера требует дальнейшего объединения SSH, API и
  временного порога; до этого снятие питания блокируется.
- NUT не сообщает `battery.runtime`; расчёт основан на абсолютном grace timer.
- HTTP API только read-only и IPv4.
- Встроенный HTTP-сервер рассчитан на локальный мониторинг, не на публичную сеть.
- Консольный `--init` в первой версии выдаёт безопасную последовательность, но
  не модифицирует Proxmox автоматически.
- Реальный тест OB/LB и полный аварийный цикл ещё не выполнены.
- Ubuntu 25.04 EOL требует отдельного обновления с проверкой NUT после reboot.
